About Multi File Converter 🔄

A powerful tool to convert files between various formats with ease

🚀 What is Multi File Converter?

This is a Flask-based web application that allows users to convert files between various formats including Word to PDF, PDF to Word, JPG to PDF, PDF to JPG, JPG to PNG, PNG to JPG. It also includes PDF merge and PDF password protection features.

✨ Key Features

📄 Document Conversion
  • ✅ Word (.docx) to PDF
  • ✅ PDF to Word (.docx)
  • ✅ Merge multiple PDFs
  • ✅ Password protect PDFs
  • ✅ Remove PDF password
🖼️ Image Conversion
  • ✅ JPG to PDF
  • ✅ PDF to JPG (as .zip)
  • ✅ JPG to PNG
  • ✅ PNG to JPG
  • ✅ Compress images
🔧 Advanced Features
  • ✅ Remove pages from PDF
  • ✅ OCR (Image/PDF to Text)
  • ✅ Add watermarks
  • ✅ Fill PDF forms
  • ✅ Compress PDFs

🛠️ Tech Stack

Python Flask HTML5 CSS3 JavaScript Bootstrap 5 docx2pdf pdf2docx img2pdf pdf2image PyPDF2 Pillow

💡 How to Use

  1. Select the conversion type from the available options
  2. Upload your file(s) using drag & drop or click to browse
  3. Configure any additional options (password, compression, etc.)
  4. Click "Convert Now" and download your converted file
